# 路由守卫和axios响应拦截器处理未登录的情况区别 
路由守卫更适合处理未登录时通过路由输入进入系统的情况，页面不会出现闪烁的情况    
axios响应拦截器适合处理用户凭证过期的情况，如接口返回401，页面会出现闪烁的情况，先进入目标页面然后再跳转到登录页

## 为什么要使用常量断言？
1. 保留字面量类型，避免类型扩宽
2. 变为只读属性，避免被修改 
3. 方便用typeof 获取类型
4. 替代部分枚举类型
```ts       
const status = {
    SUCCESS: 0,
    FAILURE: 1,
    PENDING: 2,
} as const;

// 如果不加常量断言，status.SUCCESS 的类型是number，而不是 0
```

## 条件类型 
```ts   
// 条件类型语法：T extends U ? X : Y，如果类型 T 可以赋值给类型 U，则返回类型 X，否则返回类型 Y。
// 如果 T 是字符串类型，返回 true，否则返回 false
type IsString<T> = T extends string ? true : false;

// 使用条件类型
// string extends string 为 true，所以 A 类型是 true
type A = IsString<string>;
// number extends string 为 false，所以 B 类型是 false
type B = IsString<number>;

// 使用这些类型
var a: A = true;
var b: B = false;

console.log("string 是字符串?: " + a);
console.log("number 是字符串?: " + b);
```
