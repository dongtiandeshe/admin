# 路由守卫和axios响应拦截器处理未登录的情况区别 
路由守卫更适合处理未登录时通过路由输入进入系统的情况，页面不会出现闪烁的情况    
axios响应拦截器适合处理用户凭证过期的情况，如接口返回401，页面会出现闪烁的情况，先进入目标页面然后再跳转到登录页        

# RBAC（Role-Based Access Control，基于角色的访问控制） 
目前放射卫生在线使用的权限管理就是这个方法，后端返回账号所属的角色和权限，前端保存在全局状态Zustand里   
目前放射卫生在线的路由菜单控制有个弊端，菜单渲染是通过后端返回的路由数据渲染的，react路由配置是写死的，如果用户通过路由进入到其他页面，就会出现axios报错401提醒，再返回原页面，就是页面闪烁，
