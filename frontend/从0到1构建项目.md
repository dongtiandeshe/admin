# 从零开始搭建vite+react项目    

# 初始化文件    
首先先新建个文件夹，作为存放项目代码的地方，该文件夹名为`vite-study`。  
然后执行`npm init -y`创建package.json文件。 
ok！！！初步的项目框架已经搭建好，接下来引入需要的依赖。    

1. react        
```
npm install react react-dom
```
2. vite     
```  
npm install -D vite 
```     
3. typescript   

引入了最基本的两个依赖后，接着来搞定基本的入口文件等。

# vite.config.ts配置文件    
### 情景配置
```ts   
export default defineConfig(({ command, mode, isSsrBuild, isPreview }) => {     //command命令，mode模式，isSsrBuildssr构建，isPreview预览
  if (command === 'serve') {
    return {
      // dev 独有配置
    }
  } else {
    // command === 'build'
    return {
      // build 独有配置
    }
  }
})
```
### 异步配置 
如果在配置文件中需要用到异步函数，可以如下配置。  
```ts   
export default defineConfig(async ({ command, mode }) => {
  const data = await asyncFunction()
  return {
    // vite 配置
  }
})
```
因为vite的设计，在配置文件中无法提前获取到env环境变量，可以使用loadEnv辅助函数来手动引入。  
```ts     
import { defineConfig, loadEnv } from 'vite'

export default defineConfig(({ mode }) => {
  // 根据当前工作目录中的 `mode` 加载 .env 文件
  // 设置第三个参数为 '' 来加载所有环境变量，而不管是否有
  // `VITE_` 前缀。
  const env = loadEnv(mode, process.cwd(), '')
  return {
    define: {
      // 提供从 env var 派生的显式应用程序级常量。
      __APP_ENV__: JSON.stringify(env.APP_ENV),
    },
    // 例如：使用 env var 有条件地设置开发服务器端口。
    server: {
      port: env.APP_PORT ? Number(env.APP_PORT) : 5173,
    },
  }
})
```

package.json的依赖锁定问题。    
刚刚看到了一篇文章，因为依赖版本下载的问题导致了系统出错。根本原因就是package.json内的版本号。    

```json
{
  "dependencies": {
    "antd": "^6.0.1",         //^代表版本号是6.x.x可以更新大于6.0.1的版本。比如6.1.1，6.0.3
    "react": "~19.2.0",     //~代表版本号是19.2.x，可以更新大于19.2.0的版本，比如19.2.1。
    "react-dom": "19.2.0",    //啥也不写代表锁死19.2.0版本，后续不会更新
    "react-router-dom": "^6.30.1",
    "typescript": "^5.9.3"
  },
}

```
